# Stress tests, 2026-10-17 (0.2.0)

Machine: Apple M5 MacBook, macOS. Release build (`--release`). All transfers go to the in-process local S3 server, so network time is not included. Numbers are from single runs.

Commands:

```sh
cargo test -p r2dock --release --test activity_stress -- --include-ignored --nocapture
cargo test -p r2dock-transfer --release --test stress -- --include-ignored --nocapture
```

| Test | Size | Result |
|---|---|---|
| Activity log, concurrent writers | 32 threads, 160,000 rows with hostile names (formulas, quotes, commas, line breaks, Unicode) | 3.8 s; every row written once, one header per file, every row parses to 15 columns, no formula cells, no secret |
| Activity export | 366 daily files, 1,830,000 rows (CSV and old JSONL) | 0.44 s; rows in time order, memory bounded to one day |
| Transfers, default | 404 files, 96.9 MB (4 multipart), pause all and resume during upload | upload 0.75 s, download 1.89 s; all bytes match |
| Transfers, heavy | 3,012 files, 1,306.5 MB (12 multipart, about 96 MB each), pause all and resume during upload | upload 3.21 s, download 15.28 s; all bytes match |
